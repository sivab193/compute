What High-RAM actually gives you

    
High-RAM is a runtime shape, not an accelerator: it raises host RAM
      and leaves the GPU unchanged. It matters most on the CPU and T4 runtimes, taking host
      RAM from roughly 13 GB to about 51 GB. The L4 and A100 runtimes already come with a
      large RAM allowance, so the toggle changes little there.
